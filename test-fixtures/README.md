# 测试夹具

## 公开虚构反例

`public-coach/`包含七份本轮从零编写的虚构输入与对抗性响应，不来自用户资料、客户材料或历史模型原文。每份带有`provenance.fictional: true`。纸页演练组织、岗位和经历均为虚构；其中不当职责扩写、内部警告和第三方项目数字故意作为负向输入，不能用作面试答案。

五份场景输入覆盖知识错误、真实经历类型、需求机制、不知道及未来假设；两份响应覆盖内部核对说明污染、未知团队职责/用途扩写。保留原测试的事实隔离、字段边界、版本、最终答案及刷新断言。Mock不证明真实模型准确率、缓存或响应性能。

## 仅限本地的历史原件

`coach/`七份历史输出继续留在本地，整个目录由发布白名单排除并被Git忽略。公开测试已不依赖该目录；没有覆盖、移动、删除或转贴其正文。授权未确认前不得公开。
