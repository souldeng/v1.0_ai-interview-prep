# AI 面试通（AI Interview Prep）

**基于真实简历、岗位要求与面经资料的 AI 面试准备与训练工具。**

AI 面试通是一款本地运行的 AI 面试训练应用，面向希望系统学习面试知识、准备目标岗位及复练实际面试问题的求职者。

用户可以导入简历、收集岗位 JD 和面经，由 AI 整理资料、生成针对性问题，并通过 **回答 → AI 点评 → 追问 → 重答 → 保存** 的流程持续练习。

> **项目状态：Preview / 持续迭代中**
>
> 当前版本面向个人本地使用和技术交流，核心功能已实现。真实模型生成质量、复杂文档识别效果和不同设备的使用体验仍在持续验证。

## ✨ 核心功能

| 模块 | 功能 |
| --- | --- |
| AI 基础学习 | 内置 60 道 AI 相关学习题，支持分类检索、知识学习和自主回答 |
| 个人资料库 | 导入 PDF/DOCX、文本或图片资料，提取候选经历，编辑与人工确认 |
| 岗位专项准备 | 上传并核对 JD，保存岗位分析，选择推荐题进入训练 |
| 面试资料收集 | 批量导入 JD、面经截图或文字，OCR、AI 分类、考点整理与批次归档 |
| 简历专项面试 | 围绕一段已确认经历生成问题，支持追加、重新生成、隐藏题目及撤销隐藏 |
| AI 面试训练 | 回答点评、针对性追问、再次作答、手工编辑并保存最终回答思路 |
| 训练记录 | 保留原回答、对应版本点评、重答和练习历史，支持再次练习 |
| 导出与备份 | 导出 DOCX/PDF 练习记录，支持本地文字与训练数据备份恢复 |
| 服务端用量监控 | 按功能记录模型 Token、估算费用、耗时及状态，通过终端查看报表 |

## 🎯 典型使用流程

**日常学习**

选择 AI 基础题 → 学习知识点 → 隐藏提示并自主回答 → AI 点评与追问 → 重答 → 保存自己的思路。无需 JD 或简历；看过提示不代表已经独立掌握。

**针对目标岗位准备**

导入简历与岗位 JD → 核对资料并确认本人经历 → 分析岗位要求 → 选择推荐题 → 开始练习。

也可以从“我的经历”或题库“简历专项”选择一段已确认经历，生成并保存题组，任选一道练习。

**收集面经并复练**

批量上传面经截图或粘贴文字 → AI 整理并提取问题 → 查看已归档结果 → 选择题目练习 → 保存训练记录。

实际面试中遇到的问题也可以手动录入、可选关联岗位后复练，不要求记得当时的完整回答。

## 💡 设计特点

### 真实资料驱动

面试问题可以来自基础知识、目标岗位、已确认个人经历或第三方面经，而不只是通用题库。AI 衍生题与原文题保留不同来源，不冒充企业真实面试原题。

### 注重训练过程

保留用户自己的回答、AI 点评、追问和重答，方便复习与再次练习。AI 建议不会自动替换用户最终确认的答案。

### 保留事实边界

个人经历必须经过用户明确确认，才会作为已确认个人事实使用；本人确认不等于外部核验。岗位 JD、第三方面经及 AI 推测与个人事实分开管理。

AI 内容仍可能存在错误，重要事实和面试答案需要自行核实。经历题暂不自动生成完整个人故事，最终表达由用户编辑确认。

## 🛠 技术实现

- **前端**：React、TypeScript、Vite、Tailwind CSS。
- **服务端**：Node.js、Express。
- **AI 模型**：OpenAI-compatible Chat Completions API，当前主要适配 DeepSeek Flash。
- **文档处理**：PDF.js、DOCX 正文解析、本地 OCR（Tesseract.js）。
- **本地存储**：localStorage、IndexedDB。
- **验证**：单元及接口测试、Playwright 浏览器测试。

## 🚀 本地运行

### 环境要求

- 推荐 Node.js 24；PDF.js 要求 Node.js 22.13.0 或以上。当前验证环境为 Node.js 24.15.0。
- npm、现代桌面浏览器（推荐新版 Chrome / Edge）。
- 使用 AI 功能时，自行准备兼容接口的模型 API Key。

### 1. 获取项目并安装依赖

克隆仓库后进入项目根目录：

```powershell
npm ci
```

### 2. 配置模型

将 [`.env.example`](.env.example) 复制为新的 `.env`，已有文件不要覆盖。在本地填写：

```env
MODEL_PROVIDER=DeepSeek
MODEL_API_KEY=
MODEL_BASE_URL=https://api.deepseek.com
MODEL_NAME=deepseek-flash
```

上面是 Flash 示例；模板当前的模型示例为 `deepseek-v4-pro`，请按自己账户可用的模型填写。服务不会自动切换模型。代理会追加 `/chat/completions`，不要把完整请求路径填入 Base URL。

**真实 API Key 只填在本地服务端 `.env` 中，不要上传 GitHub、放入前端 `VITE_` 变量或贴到聊天/日志。**修改后重启服务；未配置模型时仍可学习和作答，但本地辅助提示不等于专业 AI 点评。

### 3. 启动项目

```powershell
npm run dev
```

默认地址为 `http://localhost:3000`。可用 `PORT` 环境变量改端口，以终端输出为准；不同端口的浏览器本地资料相互隔离。

**当前服务监听 `0.0.0.0`，不只是本机地址；模型代理没有身份验证。请限制网络访问，不要开放公网、转发端口或分享带密钥的服务。**更多边界见 [安全说明](SECURITY.md)。

如需本地生产模式，先执行 `npm run build`，将 `NODE_ENV` 设为 `production` 后再执行 `npm run dev`。`npm run preview` 仅预览静态前端，不提供模型代理。

### 4. 检查与测试

```powershell
npm run lint
npm test
npm run build
```

`lint` 实际执行 TypeScript 类型检查，不是独立 ESLint。

自动化测试使用仓库内完全虚构的公开夹具；七份历史模型输出仅留在本地，不参与公开版本测试。Mock 回归不代表真实模型教学质量。

每次提交前执行 `npm run sync:check`，检查本地源码、Git 暂存内容与历史。单目录维护步骤见 [GitHub 持续同步](GITHUB_SYNC.md)。

## 📊 服务端 Token 与成本监控

模型请求统一经过本地服务端代理，按业务功能记录 API 实际返回的输入/输出 Token、可用的思考与缓存 Token、耗时、成功/失败状态及估算费用。缺少 usage 或细分字段时显示未知，不编造为零。

在项目根目录查看今日、本月及累计报表：

```powershell
npm run usage
# 同一命令的别名
npm run usage:report
# 查看逐请求元数据
npm run usage -- --details
```

报表支持按经历提取、岗位分析、专项选题、资料整理、追问和点评等功能查看用量、平均/P95耗时、缓存命中情况及费用。它是本地统计，不是服务商账单；**未结算预算预留不等于实际花费**。

日志默认保存为 `.local-usage/llm-usage.jsonl`，不记录简历、JD、回答正文、完整 Prompt 或 API Key，且不纳入公开文件。

可在 `.env` 中设置 `LLM_BUDGET_ENFORCEMENT=true` 开启预算保护；模板默认关闭。每日/月预算、每日调用数、最大输出和重试上限详见 [配置示例](.env.example)。限制是当前本地服务的全局限制，不是可靠的单用户配额；取消或超时不保证服务商停止计费，主动重试也可能增加费用。

## 🔒 数据与隐私

- 简历、岗位、训练等主要保存在当前浏览器；原件使用 IndexedDB Blob 保存。
- 清理浏览器数据、换浏览器或换访问端口可能导致原资料不可见；重要文件请另存。
- 主动调用 AI 功能时，相关处理文本会发送到已配置的外部模型服务。不要发送未经授权的个人、客户或公司机密。
- 图片 OCR 在浏览器本地运行，首次仍需联网下载引擎及中英文语言资源，不是首次即可完全离线。
- JSON 备份包含受支持的文字与训练数据，**不包含 IndexedDB 原始附件**；恢复不承诺跨存储原子事务。
- 暂无多用户账户、云端同步或公网模型代理的安全部署方案。

## ⚠️ 当前限制

- AI 提取、分类、出题及点评可能遗漏或出错，不保证面试结果。
- PDF 主要提取文字层；扫描正文、复杂排版及小字长截图需核对，必要时截图 OCR 或手工补文。
- 图片每张最多 10MB，另有像素/宽高保护；其他可解析文档上限 8MB。
- 请求可能等待较长时间并产生 API 费用；取消上游请求不保证撤销费用。
- 本地容量有限，达到上限会明确拒绝保存，不自动淘汰旧记录。
- 手录真实题暂不支持正文编辑/删除；专项题的移除不级联删除训练历史。
- 不保证所有手机、语音设备和文档阅读器兼容。
